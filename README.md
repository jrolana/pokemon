# POKEDEX

A simple catalogue webpage where you can list and view details of the Pokemons.

This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

## Commands

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```
